Features

Everything you need to automate

⏺

Record & Replay

Capture every mouse click, movement, and keystroke with millisecond precision. Replay at any speed with configurable loops.

👁

Image Recognition

Wait for an image to appear on screen before acting. Click buttons by what they look like, not by fixed coordinates.

📝

Script Editor

Write powerful automation scripts in Rhai — a fast, embedded scripting language with full access to mouse, keyboard, and screen APIs.

🖱

Auto-Clicker

High-frequency clicking with randomized intervals, jitter, and configurable burst patterns. Fully adjustable and hotkey-controlled.

🕐

Task Scheduler

Run macros on a schedule — every N seconds, daily at a set time, or once at a specific moment. Fully unattended automation.

🏪

Marketplace

Browse, download, and publish macros. Share your automations with the community or sell them directly in the built-in store.

🔗

Macro Chaining

Chain multiple macros together into sequences. Set loops and delays between each step for complex multi-stage workflows.

🪟

Window Targeting

Lock playback to a specific window. Coordinates are stored relative to the window — move it anywhere and macros still work.

⚙️

Profiles & Hotkeys

Save full configuration sets as profiles. Switch between setups instantly. Assign global hotkeys for hands-free control.
